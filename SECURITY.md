# Security Policy

## Supported versions

Security fixes are made in the latest release.

## Reporting a problem

Please don't open a public issue for a security problem. Instead, report it privately through
GitHub's [private vulnerability reporting](https://github.com/tahirwaseempk90/AnimationBGView/security/advisories/new).
Include what you found, how to reproduce it, and the versions affected. You'll get a reply within a
week.

AnimationBGView draws a background. It has no network access, stores no data, and has no
dependencies, so most problems will be ordinary bugs. When in doubt, report it privately anyway.
